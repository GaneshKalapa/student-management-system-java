Student Management System

Project Description

A Java-based Student Management System developed using JDBC and PostgreSQL. This application helps manage student records efficiently through database operations.

Technologies Used

- Java
- JDBC
- PostgreSQL
- Maven
- Eclipse IDE

Features

- Add Student
- View All Students
- Search Student
- Update Student
- Delete Student

Database

PostgreSQL

Project Structure

- "src" – Java source code
- "pom.xml" – Maven dependencies
- 
How to Run

1. Clone or download this repository.
2. Import the project into Eclipse as an Existing Maven Project.
3. Configure PostgreSQL database credentials.
4. Run the Main Java class.
